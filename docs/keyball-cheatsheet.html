Rules of the system

One intent, one finger position
OS mess stays inside the layer table (and the mac swap)
Ctrl-chords = commands
Super-chords = windows & desktops — both OSes consume both
App disagrees with a chord?
mac: App Shortcuts · KDE: global shortcuts — fix the app, never the finger
Anything not on CMD
cross-hand HRMs — mod on the opposite hand from the letter
NAV moves the cursor
WS moves windows & desktops
